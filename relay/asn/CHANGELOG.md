# ASN 版本更新記錄

這份檔案是更新說明的唯一來源：發版（npm run release）會取最新一段寫進 latest.json，設定的「更新」分類也從這裡顯示版本記錄。
格式：`## 版本號（日期）`，下面用「- 」條列，新版寫在最上面。

## 0.1.33（2026-10-22）
- 登入畫面換成 MSN 風背景；震動提示改成「回震動後想一下有沒有要報告的」；Claude 外掛附 asn 技能說明；手機版（安卓）第一期

## 0.1.32（2026-10-22）
- 顯示正在聽的歌（預設關，#20）；密碼小幫手：git／ssh 要密碼時由 ASN 跳窗收，AI 看不到（#26 第一期）

## 0.1.31（2026-10-22）
- 設定「個人」新增「顯示正在聽的歌」（預設關）：開了，好友會在你的狀態看到「♪ 正在聽：歌名 - 歌手」，只送歌名與歌手，暫停就不顯示（#20）
- 夥伴改名、換 session、換電腦都延續同一位：往來記錄跟著走、寄給舊名字的信自動改送新名字，開新夥伴可選「這是誰的接班」（#153）

## 0.1.30（2026-10-22）
- 沒指定收件視窗的信改交給本人（顯示「未指定收件人」），不再丟給隨便一個視窗；可在設定指定交給哪個視窗

## 0.1.29（2026-10-22）
- 設定「帳號」新增「邀請雲端代理」：產生給代理的說明與只顯示一次的金鑰、可撤銷（#13）；Claude 外掛跟著 ASN 一起更新

## 0.1.28（2026-10-22）
- ASN 打開時自動幫 Claude Code 安裝 ASN 外掛（預設啟用）；名單顯示「等你回答」「背景工作中」等狀態

## 0.1.27（2026-10-22）
- 修正：收發室剛啟動、還沒拿到視窗名單時寄來的信不會再被誤判找不到而丟掉；環境變數改用 ASN_*（舊的 IRORI_* 照樣能用，#14 第一期）

## 0.1.26（2026-10-22）
- 設定「音效」改「通知」，四個開關（#125）；偽通話第一期：講話自動寄出、回信自動念出（#99）；asn-cli recv --peek 只看不收

## 0.1.25（2026-10-22）
- 內建收發室也能投遞給 Gemini（ACP）與 Codex 夥伴（#12 第五期）

## 0.1.24（2026-10-22）
- 子代理按鈕：看各 Claude 視窗正在跑的子代理（#27）；設定新增「用量」分頁，估算 token 與費用（#52）

## 0.1.23（2026-10-22）
- 多台設備接同一串對話（#108）：登入同一帳號的電腦，AI 看到的是同一個你，回信每台都收得到

## 0.1.22（2026-10-22）
- 對話視窗上方的大按鈕列（#40）；切換模型支援自己開的視窗、開同名夥伴預設接續上次對話（#82）

## 0.1.21（2026-10-22）
- 夥伴 ID（#109）：同一個視窗改名、換電腦後仍認得是同一位夥伴

## 0.1.20（2026-10-22）
- 登入畫面改成經典即時通風格：淡藍極光背景、大頭像框；登入過會顯示上次的頭像，並在上次用的登入方式標「上次使用」。收發室替每個視窗名保留往來記錄，同名的新視窗可以讀它接手。

## 0.1.19（2026-10-21）
- 修正安裝更新後重開時誤判「已經有一個 ASN 在跑」而無法啟動；換模型重開的視窗恢復文字顏色（開視窗一律清掉繼承來的 NO_COLOR 等環境變數）。

## 0.1.18（2026-10-21）
- 你在 ASN 視窗打的字會附上本人簽章，對方收到時標成主人；AI 寄的信不受影響。名單上別台設備顯示「有新版」時可以直接按「更新」，那台會自己下載、驗簽、安裝並重開。

## 0.1.17（2026-10-21）
- 開啟時先檢查登入；登入後自動把這台電腦連到你的帳號（舊電腦自動認領、新電腦自動建立），不用再按任何鈕；設定的帳號只顯示 email 與登出。
- 修正登入後「把這台電腦連到我的帳號」按了沒反應；帳號底下的電腦數只算電腦。
- Claude 帳號可勾「自動加入」，每分鐘檢查一次目前登入的帳號。
- 內建收發室（設定裡開啟，預設關）：可接手這台的收發室、允許其他設備替這台開新視窗。
- 新增命令列工具 asn-cli（寄信、收信、房間、附件）；可切換模型；修正開了設定分頁後「開始」頁籤沒收掉。

## 0.1.16（2026-10-21）
