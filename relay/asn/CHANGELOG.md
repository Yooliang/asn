# ASN 版本更新記錄

這份檔案是更新說明的唯一來源：發版（npm run release）會取最新一段寫進 latest.json，設定的「更新」分類也從這裡顯示版本記錄。
格式：`## 版本號（日期）`，下面用「- 」條列，新版寫在最上面。

## 0.2.18（2026-11-13）
- 改善：分頁改成「對話／夥伴／通知／設定」，電腦和手機的字和順序一樣。電腦版：通知、群組、使用指引、齒輪都從左邊移到上方的分頁，群組併進「對話」，使用指引移到「設定 → 使用指引」，設備頁籤留在「夥伴」裡；任一台有未讀時，「夥伴」分頁也會亮紅點。手機：開 App 先看「對話」清單，點一則才進去（上次正在看的那一則會直接打開）；通知固定在第三格；「設置」改名「設定」。
- 改善：設定裡管震動、聲音和 App 關著時通知的分類，電腦原本叫「通知」、手機叫「提醒」，現在都叫「提醒與聲音」。
- 新功能：設定 →「外觀」可以選「復古 Aero（原本的樣子）」或「現代（預覽）」。選了所有視窗馬上換，不用重開；預設是復古 Aero，升級後樣子不變。現代外觀目前先換配色（米白底、青綠主色），對話畫面依設計稿重排在 0.2.19。
- 新功能：手機看別台電腦的終端時，可以用下方輸入框打字（0.2.17 的已知問題）。
- 新功能：電腦版看本機夥伴的終端時，下方輸入框送出的字會直接打進終端（0.2.17 的已知問題）。
- 改善：輸入框送進終端前會先去掉控制字元；多行內容在等確認時，前一段不會被後一段蓋掉。
- 改善：每台設備（電腦、手機、雲端代理）只有一個名字，所有地方顯示同一個。你可以從任何一台自己的設備替另一台改名，改過的名字不會在對方重新啟動時被蓋回去。
- 改善：「認得的電腦」併進設定的設備頁，每台設備的指紋、QR code、改名、允許的項目和忘記都在同一個地方。
- 改善：電腦版在設定 → 設備按「忘記」時，會先跳確認框，按「取消」就不會忘記。
- 修正：電腦重開機後，橋不會再把別的程序誤認成「另一個橋還在跑」。
- 改善：手機匯出到「下載」時檢查得更仔細。

## 0.2.17（2026-11-12）
- 新功能：手機可以替電腦登入 Codex（只登入，不會幫你安裝）。電腦要先升到 0.2.17，升級後請在電腦設定裡重新勾一次「允許這支手機替這台登入」。
- 新功能（電腦版）：看別台夥伴的終端時，下方輸入框打的字會直接送進那個終端，原本的「打字」按鈕拿掉了；按鈕在對話畫面寫「傳送」，在終端畫面寫「送出」。
- 改善：電腦版切到別的分頁再切回來，終端畫面會保留；你打字打到一半離開，回來要自己按「重新看」才會接上。
- 改善：電腦版終端分頁在背景時暫停讀取，比較省資源。
- 改善：手機看終端時，提示移到下方狀態列；在終端上左右滑不會切到別的分頁。
- 改善：手機「認得的電腦」頁可以直接確認指紋。
- 改善：「我的帳號」卡片的時間移到帳號後面，正在讀額度的那台電腦在設備按鈕上標藍線。
- 改善：手機上的節點金鑰和登入資料改用系統金鑰庫加密保存，也可以換一把新的節點金鑰。
- 修正：重開機接回時，你自己關掉或封存的視窗不會再被接回來。
- 修正：同一段對話不會再開成兩個視窗。
- 已知問題：手機看終端時還不能打字，0.2.18 會補上。
- 已知問題：電腦版看本機的終端時，還不能用下方輸入框打字，0.2.18 會補上。

## 0.2.16（2026-11-12）

- 改善：手機要記住或忘記一台電腦時，要先通過指紋或螢幕鎖驗證。
- 改善：沒有名字的電腦顯示「未命名的電腦」，你可以在電腦和手機的「認得的電腦」裡自己幫它取名。
- 新功能：需要你本人確認的畫面（權限框、外來訊息框、要在你電腦的終端機裡打字或替你回答權限框之前的確認），手機 App 關著時也會跳出「ASN 需要你確認」的通知，內文會寫是哪一台電腦（修正 0.2.15 的已知問題）。
- 新功能：設定 →「視窗與系統匣」多一個開關「ASN 意外關閉時自動重新開啟」，預設關。只在 ASN 意外關閉時重開，你自己按結束不會重開。目前只有 Windows。
- 修正：Claude 的額度不會再記到別的帳號底下（包括切換帳號之後，原本就開著的視窗）。
- 修正：Claude 已經沒有的額度（例如最高方案拿掉的 5 小時限制）過了重置時間就不再顯示舊數字。
- 修正：Gemini 閒置的視窗不會再用舊的額度數字蓋掉比較新的數字。
- 改善：額度判斷改成以來源為準，不再因為數字看起來不合理而擋下真實的讀數。
- 改善：名單上只顯示、沒有接管的視窗，狀態寫「執行中・僅顯示」，也不再提供封存。
- 改善：後台已經不認得的舊好友，改成在本機封存，不再顯示「不用封存」。
- 修正：手機的設備詳情，詳情區塊和設備按鈕不會再橫排疊在一起。

- 修正：收到推播之後約 3 分鐘內，再來的信不會響（0.2.14 的已知問題）。現在手機在背景時都會響。
- 改善：終端服務停了，或 ASN 看不到它時，會寄通知給你。
- 改善：回信暫時寄不出去時，會先保管起來，網路恢復後自動補寄，對方不會收到兩封；保管的檔案壞掉時會通知你。
- 改善：Claude 跳出要你確認外來訊息的框時，電腦和手機都會提示，要你本人按了才放行；在別台打字時遇到這種框，也會先停下來。不放行時送出的是取消，不是 Enter。
- 修正：確認框按 Enter 不再等於允許。別台要在這台打字時跳出的確認框，第一顆按鈕改成「不允許」，要明確按「允許」才會放行。
- 修正：別台要在這台打字的確認框，逾時或取消之後再按，也不會放行。
- 改善：自己帳號的電腦之間，在別台打字不用每次都按允許。第一次還是會問；在別台打字時，被打字的那台照樣會亮紅條，隨時可以按結束。想每次都問，可以在設定 → 認得的電腦取消勾選。
- 改善：電腦版的系統通知移到左側固定的「通知」頁籤。
- 改善：電腦版看終端時，狀態改到視窗最下方的狀態列，終端區和訊息框對齊。
- 改善：整合模式的視窗變窄時，對話區的排版會跟著調整，不會被擠壞。
- 改善：設定頁會說明這次夥伴為什麼開在一般視窗，以及怎麼恢復。
- 修正：終端畫面裡有 emoji 時，游標位置對不上。
- 改善：手機看終端時，輸入框留在最下面，終端縮到它上方；有新畫面時會自動捲到游標那一列，你往上捲著看的時候不會被拉回去。
- 修正：已經過了重置時間的額度，不會再被當成還在計算。
- 改善：切換帳號、存設定時畫面比較不會卡住。
- 已知問題：需要你本人確認的框，手機 App 關著時不會跳通知，要打開 App 才看得到，下一版修正。

- 改善：帳號卡片的「用在：」和「切換到…」合成一排設備按鈕，電腦和手機都一樣；切不過去的設備，按鈕下方會用小字寫原因，例如「那台的 ASN 沒開著」。視窗很窄時，額度條會換行，不會把卡片撐出畫面。
- 改善：額度開關搬到設定 → 帳號裡各服務自己的區段；原本的「額度回報」改成 Claude 區段裡的一個開關。

- 改善：各台電腦收發室發的通知（例如「找不到名叫…」）改用「ASN 通知」的名義寄出，第一行寫是哪台設備；通知內文不再用「這台」。
- 修正：網路不穩、寄信要重送時，對方不會收到同一封信兩次。
- 修正：網路一時連不上時，寄信會等一下自動再試；回信最後還是寄不出去時，會在視窗裡告訴你，不會默默不見。

- 修正：設備頁的登入狀態不會再重複列出 Gemini、Grok；開新夥伴時，兩者各只列一次。

- 改善：看終端、終端服務的監看、背景夥伴的人數，這幾個地方查狀態的次數變少，電腦比較不會被拖慢。
- 改善：終端服務中斷時，會把原因記進記錄，之後再發生時比較好查。

## 0.2.12（2026-11-09）
- 新功能：手機可以看自己電腦上夥伴的終端（只能看，不能打字）。在夥伴的對話頁上方切到「終端」就會開始看，切回「訊息」或離開對話就結束。每次查看前都要先通過指紋或螢幕鎖；手機沒有設定螢幕鎖的話不能看。被看的那台電腦照樣會出現紅條並收到通知信。
- 新功能：電腦設定頁多一個開關「允許移動設備查看終端」，預設開；關掉後，手機就不能看這台電腦上夥伴的終端，正在看的也會馬上結束。電腦之間互看不受影響。
- 新功能：額度來源（設定 → 設備與帳號 → 額度來源，全部預設關）：可以讀 Grok、Gemini 的額度，Gemini 會寫出目前算在哪個帳號名下；可以加入 MiniMax 帳號（輸入 email 和 key，最多 2 個，key 存好後不再顯示，只能移除後重新加入，目前只有 Windows 能設定）；讀不到時，原因會留在畫面上，例如「登入失效，要重新登入」。
- 新功能：「我的帳號」每個帳號都可以產生查詢代碼，讓別的程式用這個代碼查這個帳號的額度。代碼只顯示一次；重新產生或撤銷後，舊代碼立刻失效。
- 新功能：Grok、MiniMax 的額度也會出現在帳號列表，電腦和手機都看得到。
- 新功能：Claude 的額外帳號（另外登入在專用資料夾的帳號）可以讀額度，也可以選擇快到期時自動換新；兩個都預設關，自動換新要按兩次才會打開。沒有這個資料夾的人看不到這一區。
- 改善：「通知」對話分得出是哪一台：每則通知的上方會寫「通知 · 設備名」，收發室自己發的通知開頭也會加上設備名。
- 改善：從手機或別台電腦開新夥伴時，Gemini（agy）和 Grok 也能開進那台的 ASN 終端（那台要開著終端服務，並允許其他設備替它開新視窗）。手機開新夥伴頁會說明「會照那台電腦的設定，開在前台或背景」。
- 修正：設備清單的「雲端」標示，剛開 ASN 時讀取失敗的那台，之後會自動重讀，不會一直顯示成電腦。
- 已知問題：手機橫向看終端時，終端畫面會被擠到看不見，請先用直向看，下一版修。電腦關掉開關、切到背景的情況還沒在實機上驗過，用起來有問題請回報。
- 已知問題：從手機替別台電腦開 Gemini、Grok 進終端服務，還沒在實機上驗過。
- 已知問題：後台送出的部分通知，內文還會寫「這台」，下一次後台更新會改掉。

## 0.2.11（2026-11-09）

- 新功能：手機版設定「通知」多一列「App 關著時也通知我」：打開後，手機就算沒開 ASN，有新訊息也會跳通知（只說「有新訊息」，內容要打開 App 才看得到）。這個功能已經內建，等設定好 Firebase 才會開；還沒開之前，這一列不會出現。

- 修正：手機版的帳號不會再被列成可以「切換到這支手機」（手機上不跑夥伴）；替別台電腦切換照舊。
- 修正：看別台的畫面、在別台打字時，上方寫的是設備名稱，不再顯示成代號（例如「正在看「H」」）。
- 修正：電腦版名單上方「正在聽的歌」會顯示了；Claude 外掛在背景裝好時會更新狀態；Claude、Grok 帳號自動加入後，會重抓清單並顯示「已自動加入 …」。
- 改善：夥伴的名字不能取成「ASN 通知」，也不能以「收發室」結尾，這兩種留給系統通知用。
