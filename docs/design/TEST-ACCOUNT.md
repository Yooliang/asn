# AI 專用測試外部帳號與固定測試群組

小良哥 2026-10-30 核可（群組 #1695 第 1 點）。目的：跨帳號功能（外部成員、群組權限、簽章、附件）部署後，AI 能自己端到端驗證，不必每次靠單元測試加人工。起因是 #561（外部成員傳附件）部署後沒有第二個帳號可測。

本文件只定做法，不含任何帳號憑證。

## 一、帳號

- 「小良哥保管的公司測試帳號」。ASN 只有 Google／GitHub 登入（沒有信箱別名這條路），所以用公司的 Google 帳號，由小良哥本人建立與保管。
- 另開一個**獨立的 ASN，跑在另一個 Windows 使用者底下**（例如 `asntest`），由小良哥登入一次。登入憑證只存在那個使用者的資料夾裡（依 `ACCOUNT-ME.md`，憑證只在 Rust 端）。
- **為什麼不能只用獨立資料夾**：ASN 讀的是整個 Windows 使用者共用的 `~/.claude/sessions`，不受 `ASN_HOME` 影響；同一個使用者開第二份 ASN，會把真夥伴的視窗列給測試帳號。換成另一個 Windows 使用者，才有各自的 `~/.claude`，看不到真夥伴。
- 機器不限家用機，工作機也可以，由小良哥決定；兩台都不要把測試用的 Windows 使用者放進任何真夥伴的工作資料夾權限。
- AI 看不到、也不需要看到任何密碼或憑證。repo、群組、往來記錄都不寫帳號以外的任何東西。

## 二、固定測試群組

- 由小良哥主帳號建立一個固定的「[測試]外部成員」群組，用一人一次、一天內有效的邀請連結把測試帳號加進去。
- 群組成員只有：小良哥主帳號、測試帳號、測試用節點。**測試帳號不加入任何其他群組，也不擁有任何真夥伴的節點。**
- 測試帳號與主帳號是不同帳號、不同租戶，正好是標準的外部成員，可驗 #561 那類情境。

## 三、怎麼驗證

- 走**畫面**那條：獨立 ASN ＋ smoke（沿用 `scripts/smoke-ui.mjs` 的做法）。**不新增測試入口**，因為登入憑證只在 Rust 端，`asn-cli` 沒有簽章，加入口會多出攻擊面。
- 每個端到端腳本送任何東西之前，先斷言「目前群組 id ＝ 固定的測試群組 id」，不符直接中止，防止誤送進真實群組。
- 只用固定的假內容；測完清掉附件與訊息。

## 四、不碰真實成員的保證

1. 測試群組沒有任何真實成員。
2. 測試帳號沒有其他群組、沒有真節點。
3. 腳本的群組 id 斷言（三）。
4. 邀請連結一人一次、一天內有效；不重複使用。
5. **測試 ASN 跑在獨立的 Windows 使用者底下**，讀不到真夥伴的 `~/.claude/sessions`、工作資料夾與節點金鑰；第一次登入後，用該使用者的 ASN 名單確認「沒有任何真夥伴」才算建好。
6. 要輪替或停用時，由小良哥在主帳號把測試帳號移出群組即可，不涉及任何真資料。

## 五、現況

- 測試群組：待上一步完成後建立。
- 腳本：待群組建立後，由西川寫並審。

## 六、補充（改用專用新電腦）

小良哥 2026-10-30 改為：用**一台專用新電腦**當測試帳號機（他回家後設定）。這取代第一節「另一個 Windows 使用者」的做法，因為專用電腦本來就沒有主帳號與真夥伴，隔離最徹底。

### 6.1 這台電腦的規矩

1. **機器專用**：只登入測試帳號（公司 Google 帳號），不登入小良哥主帳號，不放任何真夥伴、真工作資料夾、節點金鑰或 `~/.asn` 的真資料。
2. **標準使用者**：ASN 跑在標準（非系統管理員）Windows 使用者下；管理員能讀其他使用者的 `~/.asn`，雖然專用機上沒有別人的資料，仍照此做，避免之後有人把真資料放上去。
3. 這台電腦上的 Claude 視窗只有測試用的，不接真專案。

### 6.2 AI 怎麼操作那台的 ASN（方案，待小良哥確認）

目標：AI 能在那台跑端到端腳本，**全程不碰任何密碼**。登入由小良哥本人做一次，之後只靠已存的登入狀態。

- 由小良哥在那台建一個**排程工作**，在測試使用者登入後啟動 ASN，並開本機除錯埠（WebView2 的遠端除錯，埠只綁 `127.0.0.1`，不對外）。這一項要先在那台實機驗證：WebView2 是否吃得到除錯參數、ASN 啟動時環境變數是否帶得進去；驗證不過就退回下面的備案。
- AI 到那台的路：沿用既有的遠端連線（ZeroTier 加金鑰登入的 SSH，不用密碼），再用連線轉送的方式連到那台的本機除錯埠；除錯埠不開到網路上。
- 腳本沿用 `smoke-ui` 的做法驅動畫面，每支腳本送任何東西前先斷言群組 id ＝ 固定測試群組 id。
- **權限範圍很小**：除錯埠能控制的只有測試帳號的 ASN；測試帳號只在測試群組，最壞情況只影響測試群組。
- 備案（若除錯埠做不到）：小良哥在那台手動操作、AI 只讀結果（從測試群組讀訊息與附件），或在那台放一支只讀的狀態回報；兩者都不需要 AI 取得任何登入憑證。

### 6.3 清理

只用現有的刪除與收回功能（刪訊息、收回附件、退出群組）。**要用 SQL 直接刪正式資料庫的資料，必須先經小良哥點頭**（屬於刪除正式資料）。
