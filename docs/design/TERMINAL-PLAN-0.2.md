## 一、目標

1. **0.2.0**：夥伴的終端全部活在 wezterm-mux-server 裡，不需要桌面；GUI 只在有人要看時才接上。桌面斷線照樣能開、能喚醒。
2. **0.2.1**：讀畫面判斷夥伴卡在哪（登入、信任資料夾、權限詢問、額度、未知停滯），標在夥伴清單與手機，附上由 ASN 事先定好的按鈕。
3. **0.2.2**：本人從別台電腦或手機看夥伴的終端畫面（只能看）。
4. **0.2.3**：本人遠端打字（要本人簽章、每次確認、有效時間、留紀錄）。
