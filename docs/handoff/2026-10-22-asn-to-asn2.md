## 二、合併與發版流程

- GitHub Actions 因帳單停擺 → 合併前**自己在本機跑完全套**：
  `cd supabase/functions && deno test -A _shared/`；`relay/machine`、`relay/cloud-agent`：`node --test --test-force-exit test/*.test.mjs`；`relay/asn`：`npm ci --ignore-scripts && npm test`、`npm run test:rust`。
- 已知偶發（重跑或單跑會過，不算失敗）：cloud-agent `env-preflight`（Node 25 libuv 斷言）；Rust 幾個逾時類測試（`acp_子程序的_pid…`、`agy_太久沒動靜…`、`claude_mod…真子程序_逾時…`）在多人同時編譯時會隨機失敗。根目錄 `tests/` 有 2～17 項舊失敗（裝了 pglite 時 17 項），main 上也一樣。
- 合併：`gh pr merge <n> --merge --admin`；合併後 `git pull` 若太快會拉不到，`ls supabase/migrations` 確認新檔在再套。
- 部署順序：migration（`npx supabase db query --project-ref etccgmkrosbzpltudlgt --linked -f <檔>`）→ relay 函式（`npx supabase functions deploy relay --project-ref etccgmkrosbzpltudlgt --no-verify-jwt`）→ 發版。改寫既有函式前先把線上定義抓下來 diff。
- 發版（`relay/asn`）：
  - 電腦版：`npm run release -- --notes "…"`
  - 安卓：先設 `JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"`、`ANDROID_HOME=%LOCALAPPDATA%\Android\Sdk`，再 `npm run release:android -- --notes "…"`
  - 官網：`cd site && npx firebase-tools deploy --only hosting`；CDN 要等一下，用 `Cache-Control: no-cache` 查 `update/latest.json`、`update/android.json`。
  - 提交版本檔：CHANGELOG、package.json、Cargo.*、tauri.conf.json、`relay/claude-mod/.claude-plugin/plugin.json`、`site/public/update/latest.json`、`android.json`（APK、exe 已在 .gitignore）。
- 更新兩台：家用機直接 `ASN_<版本>_x64-setup.exe /S` 後重開 `%LOCALAPPDATA%\ASN\asn.exe`；工作機在家用機 ASN 名單上按它旁邊的「更新」（UI Automation 按 InvokePattern，不動滑鼠）。手機會自己跳更新。
