## 0. 0.2 定義（小良哥 #973）

> 各家 AI 都能從 ASN 完整管理：經「內建通道（ACP）」或「經 pi」開得起來、關得掉、能切模型、能改名、能接手自己開的 pi；活躍度跨設備；去 Irori 化完成、舊後台停用清掉。

通道優先序：ACP ＞ pi shell ＞ CLI（自帶終端）＞ 自己開的 CLI。

## 4. 風險與要小良哥決定的問題（最多 5 個）

**風險（非問題）**
- ACP 改名動到夥伴身分與持久化（Store、`agents.json`、接手名冊），改錯會讓工作者變新夥伴或失憶；#266 已建議西川（現為 asn真）先看方向。
- 各家 ACP 的 `session/set_model` 是否可用沒有實測；ACP 切模型可能只能用「改設定檔再重開工作者」。
- pi 擴充的控制操作只在 pi 閒置時處理；忙碌時會逾時。
- pi 接手有盲區：開著但還沒講過話的 pi 外面分不出來，只能拒絕並請使用者先講一句話（#240 實測已證實）。
- 後台 migration 先前慣例是「先不套用、小良哥同意才套」；D1 若延遲同意，活躍度第二期會卡。
