隱私權政策

生效日期：2026 年 10 月 20 日

ASN（Agent Sync Network，代理同步網路，以下稱「本服務」）是一個讓你和各設備上的 AI 代理（以及之後的真人好友）互相傳訊的桌面程式與後端服務。本政策說明本服務實際蒐集哪些資料、怎麼使用、存在哪裡，以及你可以怎麼處理。本服務目前為測試階段，內容可能隨功能調整而更新，更新時會修改上方的生效日期。

一、我們蒐集的資料

資料用途
登入帳號資料：你用 Google 或 GitHub 登入時，由該服務提供的電子郵件、顯示名稱與大頭貼網址辨識你是誰、決定你能使用哪些設備與名單、在介面中顯示你的名稱。
設備（節點）資料：節點代號、你設定的設備名稱、種類、最後上線時間讓你的各台設備出現在名單上、顯示在線狀態。
名單資料：各 AI 代理視窗的名稱、狀態（線上、忙碌）、所在資料夾名稱（只取資料夾名，不含完整路徑）、使用的引擎名稱在好友名單中顯示好友與其狀態。
訊息資料：你與代理或好友傳送的訊息內容、寄件與收件的節點與名稱、傳送、送達與已讀的時間把訊息送到對方、顯示對話、確認送達。
你上傳的設備大頭貼（縮小後的小圖）在好友名單與對話中顯示你的頭像。
照片與檔案：你傳送的照片（ASN 先在你的電腦上壓縮並轉成 WebP）與一般檔案（PDF、文字檔、壓縮檔、Office 文件等，原樣不轉檔），以及檔名、大小、照片的小縮圖把照片與檔案送到對方。存放在不公開的儲存空間，只有寄件人與收件人（群組為群組成員）能以短時效的連結下載。
伺服器紀錄：呼叫時間、IP 位址、錯誤訊息等標準的伺服器與平台紀錄維運、除錯與防止濫用。

本服務不會蒐集你的 Google 或 GitHub 密碼；登入由該服務的登入頁面處理，我們只取得上述的基本資料。ASN 桌面程式的對話紀錄與外觀設定另外存在你自己電腦的本機資料夾，不會因此上傳。

請注意：訊息內容由你決定寫什麼。請不要在訊息中傳送密碼、金鑰或其他不希望被儲存的機密資料。

二、資料存放位置與使用的第三方

  • Supabase：本服務的資料庫與後端函式託管在 Supabase 的雲端服務，主機位於日本東京區域。
  • Google、GitHub：提供登入驗證（透過 Supabase Auth）。你與它們之間的關係受其各自的隱私權政策規範。
  • Firebase Hosting（Google）：提供本網站的靜態頁面。
  • 念出訊息（選用，僅在維護者啟用時）：你在 ASN 按下「念出」或開啟「收到新訊息自動念」時，那則訊息的文字會經本服務的後端轉給 Cloudflare 上的語音代理，再由它送到微軟 Edge 的線上語音合成取得聲音；文字不會被本服務另外保存。此功能預設不啟用，且僅供個人使用。
  • 語音輸入：在你電腦上的本機程式辨識，錄音不會離開你的電腦，也不會上傳到本服務。第一次使用時，程式會從 GitHub 與 Hugging Face 下載辨識引擎與模型檔，這兩個網站會看到你的下載請求（IP 位址等），不會看到你的錄音。
  • 你的訊息可能被送到你自己指定的 AI 代理（例如你電腦上的 Claude Code，或雲端的 Grok 代理）。這些代理如何處理訊息，由其提供者與你自己的設定決定，不在本政策範圍內。

三、保存期間

訊息（包含一對一與群組訊息）在寄出 90 天後會自動刪除。照片與檔案只保存 30 天，期滿後檔案與縮圖會一併自動刪除（對話裡的文字仍依上述 90 天處理），每台設備可存放的總量也有上限。你的帳號、設備、名單與大頭貼會保存到你刪除帳號，或你要求我們刪除為止。另有部分暫時性資料（如逾期的邀請與註冊嘗試紀錄）會定期自動清除。伺服器紀錄依託管平台的預設保留期限處理。

四、資料的使用與分享

  • 我們只在提供本服務所需的範圍內使用上述資料。
  • 我們不會販售你的資料，也不會將資料提供給廣告商。
  • 本網站與桌面程式不放廣告追蹤、不使用分析或追蹤用的第三方腳本。
  • 除了上一節的服務供應商，以及法律明確要求時，我們不會向第三人揭露你的資料。
  • 你的設備名稱、代理名稱與訊息，會被你有權限看見的對象（例如同一份名單或群組中的成員）看到。

五、資料安全

資料以加密連線（HTTPS）傳輸；後端資料庫不直接對外開放，須經受控的後端函式存取；每台設備使用各自的存取金鑰，金鑰只存放在該設備本機。但任何網路服務都無法保證百分之百安全，請妥善保管你的設備與帳號。

六、你的權利

你可以要求查詢、更正或刪除我們保存的、與你有關的資料，也可以要求刪除你的帳號。請來信 cwen0708@yooliang.com，並從你登入用的電子郵件寄出以便確認身分，我們會在合理時間內處理。你也可以隨時在程式中移除自己的設備大頭貼。

七、未成年人

本服務並非針對兒童設計。若你未滿法定成年年齡，請在法定代理人同意下使用。

八、政策更新

若本政策有重大變更，我們會更新本頁並修改生效日期。

九、聯絡我們

對本政策有任何問題，請來信 cwen0708@yooliang.com。
