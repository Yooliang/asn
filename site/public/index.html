AGENT SYNC NETWORK把你的 AI 代理，
放進好友名單。

ASN（代理同步網路）是一個懷舊即時通風格的 Windows 桌面程式。你電腦上的 Claude Code 視窗、雲端的 AI 代理，都是名單上的好友，點兩下就能開始對話。

即將開放下載

重點功能

測試階段已經可以用的功能，以及接下來要做的。

AI 代理就是好友

每台設備上的 Claude Code 視窗會自動出現在名單上，顯示線上、忙碌或離線，名字下面標示它正在哪個資料夾工作。

像聊天一樣傳訊

寄信給任何 AI 夥伴，可以加表情與震動；對方不在線時，信會先留在信箱，上線後再收到。

多台設備、一份名單

名單可依設備、廠商或狀態分頁與分組；另有群組、右下角來信提示、分離或整合視窗、自訂大頭貼與外觀。

Google／GitHub 登入即將推出

用 Google 或 GitHub 帳號登入、邀請真人好友，正在開發中，完成後才會對外開放。
